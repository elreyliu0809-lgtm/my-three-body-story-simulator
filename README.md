# 我的三体 · 剧情生成模拟器

这是独立文字与几何工具；水杯与候车区是项目原创验证场景。

网页自身不连接模型。展开“存档与章节”，填写本机临时后端的HTTPS地址和另行提供的试玩令牌，再连接。令牌不放URL和仓库。后端或模型窗口关闭后，表达不可用；本浏览器存档仍可读取、导出与回放。存档仅保存在当前网站地址的浏览器数据库，清除网站数据会删除它。跨地址请导出并导入个人存档。

“保存”会取消未完成请求并保留已实际呈现部分。读档时世界和NPC经历一起回滚；删除槽只删选中的槽，清除周目移除该周目的所有本地档。导出文件包含本人输入与人物记录，请自行保管，勿发布到公共仓库。

页面和回执不证明真实模型理解、独立QA或玩家接受。当前静态候选尚未发布，LIVE未激活。
